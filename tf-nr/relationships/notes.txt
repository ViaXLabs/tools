Two new pieces, both tested offline end-to-end (fake NR entities + fake AWS resources, since I can't reach either live API from here):

**`aws-discover`** — queries AWS directly with boto3 (read-only List*/Describe* only) for ECS clusters, ECS services, EKS clusters, RDS instances, and RDS clusters, across whatever regions you give it. Saves everything to `outputs/data/aws_inventory_<ts>.json`.

**`match`** — reconciles those AWS resources against your New Relic graph, exactly for the "not named the same" problem: it normalizes both sides (lowercase, hyphen/underscore swaps, prefix stripping) and tries exact match first, then fuzzy string similarity as a fallback, logging *which two strings it compared* for every result so you're never guessing why something matched or didn't. Unmatched resources are flagged rather than silently dropped.

The key thing for "flexible going forward": **all the matching rules live in `config/aws_match_rules.yaml`**, not in code. Adding ALBs, S3 buckets, whatever else later means adding a fetch function + a config block — the matching engine itself never changes. I actually caught a YAML-quoting bug in that config during testing (colons in `strip_prefix:arn:aws:ecs:` were getting misparsed as a nested mapping) and fixed it — glad I ran it against real fixture data rather than just eyeballing it.

`--report` overlays the AWS resources onto the same interactive graph as before — squares for AWS, circles for New Relic, edges color-coded by match confidence (green/amber/red) — plus a dedicated table sorted so anything unmatched is easy to find and go fix by hand.

One thing worth flagging: the `nr_entity_types` I put in the default config (`AWSECSCLUSTERENTITY`, `AWSEKSCLUSTERENTITY`, etc.) are my best knowledge of New Relic's AWS-integration entity types, but you should confirm the actual ones in your account with `nr-rel schema` or by looking at a `report` output before trusting the matcher's filtering — if they're off, resources just won't get matched (safe failure, not silent wrong-matching), but it's worth a five-minute check.
