Before I hand it over — a few likely reasons Cypress 13 turns into 15 inside the image, in rough order of how often I see them:

1. **ARG scoping bug** — if `ARG CYPRESS_VERSION=13` is declared *before* `FROM` but not re-declared *after* it, the value doesn't carry into the build stage, so the `RUN npm install cypress@$CYPRESS_VERSION` line silently installs with an empty variable → npm grabs latest.
2. **Docker layer caching** — an old layer built during a "give me latest" experiment gets reused because the `RUN` line that installs Cypress doesn't actually reference the ARG, so Docker doesn't see it as changed and never invalidates the cache.
3. **Unpinned range in package.json** — something like `"cypress": "^13.0.0"` won't jump to 15, but `"cypress": "*"` or `"latest"` will, especially if `npm ci` isn't used (which needs the lockfile copied in first) and `npm install` re-resolves against the registry instead.
